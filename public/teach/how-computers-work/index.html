CPU — Program 1

Central Processing Unit

Greetings CPU! Your job as the Central Processing Unit (CPU) is to execute the following program:
  • Math commands like "Add 5 to x" or "Subtract 3 from y" — ask Memory for the current value, work out the new value yourself, then tell Memory to store it.
  • Drawing commands like "Plot (x,y)" — ask Memory for the current values of x and y, then tell the Display to plot them.
Be sure to check off each line of the program as you finish it (so that you don't lose track of where you are).
