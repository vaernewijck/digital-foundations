Central Processing Unit

Greetings CPU! Your job as the Central Processing Unit (CPU) is to execute the program below, one line at a time. It uses two kinds of commands:
  • Math commands, for example "Add 5 to x" or "Subtract 3 from y": ask Memory for the current value, work out the new value yourself, then tell Memory to store it.
  • Plot (x,y): ask Memory for the current values of x and y, then tell the Display to plot that point.
Check off each line as you finish it, so you don't lose track of where you are. When you reach DONE!, the Display can show the picture.
