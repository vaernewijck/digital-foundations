Collections API v1

Shipment records of the museum's transport crates. Read-only. Every address returns JSON.

One shipment

GET shipments/{crate_id}.json

Replace {crate_id} with the ID of a transport crate, for example shipments/CR-012.json. An ID that does not exist returns 404 Not Found.

FieldMeaning
crate_idID of the crate
artworkObject: the artwork inside the crate
original_destinationDestination ID when the shipment was first scheduled
current_destinationDestination ID now
statusscheduled, in_transit, delivered or departed
carrierObject: the external transport company and its booking number. null when no carrier is registered
eventsList: everything that happened to this shipment, oldest first. workstation is null when a scanner logged the event, not a person
