The steps for the tools on your laptop. This does not tell you what to look for.

Open a file in VS Code
  • Unzip the download first: double-click the .zip file.
  • Drag the file onto the VS Code window, or File > Open.
  • Line numbers are on the left.
  • Search: cmd+F (Windows: ctrl+F). Type a word or an ID. The arrows jump to the next match.
  • VS Code opens text files: CSV, TXT, XML, JSON. A picture (PNG, JPG) opens in your image viewer.
Import a CSV in Google Sheets
  1. Go to sheets.new. That opens a new, empty sheet. You need a Google account, which is free.
  2. File > Import > Upload, and pick the CSV file.
  3. Choose "Replace current sheet" and click Import data. Google Sheets finds the commas by itself.

Video: How to Import a CSV in Google Sheets

Prefer Excel or Numbers? That works too. If Excel puts every row in one single column: select column A, then Data > Text to Columns > Delimited > tick Comma > Finish.

Filter in Google Sheets
  1. Click a cell in the table, then Data > Create a filter. Every column name gets a filter icon.
  2. Click the icon in a column name > Filter by condition > for example "Text contains", and type what you are looking for. Click OK.
  3. Or untick values under Filter by values, to keep only the ones you want.
  4. You can put a filter on several columns at once. Only rows that pass every filter stay visible.

Video: How to Filter Spreadsheet Data in Google Sheets

To sort: the same icon, Sort A to Z. On a time column that puts the rows in order of time.

Read JSON
  • { } is an object: a set of "key": value pairs.
  • [ ] is a list. A list can hold objects, and an object can hold another object.
  • null means: no value.
  • Open it in VS Code and search with cmd+F (Windows: ctrl+F). In the browser works too: Chrome has a "Pretty-print" box at the top, Firefox shows a tree.
Read XML

XML uses tags, like HTML. <status>active</status> is a value with a label around it. A tag can also carry values in its opening part: <camera id="CAM-01">. Open it in VS Code.

Photo metadata

A photo file carries data about itself: when, with which device, sometimes where. Always use the downloaded file, never a screenshot of it.

  • Mac, Preview: open the photo, then Tools > Show Inspector (cmd+I). Click the tab with the (i). You get tabs such as General, Exif and GPS.
  • Windows: right-click the file > Properties > Details. Scroll down to GPS. Windows writes a position as 50; 49; 30: degrees, minutes, seconds.
  • Any computer: search for "online EXIF viewer" and upload the file.
How an API address is built

https://api.irail.be/liveboard/?station=Kortrijk&format=json

  • https://api.irail.be is the server.
  • /liveboard/ is the path: which kind of data you want.
  • After the ? come parameters, name=value, with & between them.

Some APIs put the choice in the path instead: .../shipments/CR-012.json. Either way: change one part of the address and you get other data. Ask for something that does not exist and you get a 404.

You type the address in the address bar of your browser, like any web address.

Find a position on a map
  1. Find the latitude and the longitude in the photo's metadata.
  2. Type them in the search box of Google Maps, latitude first, and press Enter. Google Maps understands degrees with the symbols, 50°49'30"N 3°15'52"E, and decimals, 50.825, 3.2644.
  3. On Windows the position looks like 50; 49; 30. Type it with the symbols: ° after the degrees, ' after the minutes, " after the seconds, then N for the latitude and E for the longitude.
  4. A pin marks the spot. The name of the place and the city are below the search box.
