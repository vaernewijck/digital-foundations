What this is

CARDIAC — the CARDboard Illustrative Aid to Computation — is a paper computer designed at Bell Telephone Laboratories in 1968. It illustrates how a computer works without being one: you are the power supply and the control unit. You move the sliders, carry the numbers, and walk the ladybug from cell to cell. Everything a real machine does electrically, you do by hand — which is exactly why it teaches so well.

One machine cycle

  1. Fetch. Look at the cell the bug sits on. Set the three sliders so the instruction register shows that cell's contents.
  2. Advance. Move the bug ahead one cell.
  3. Test. Glance at the accumulator-test window — it only matters for op code 3, where a minus sign makes the bug jump.
  4. Execute. Read the sentence in the instruction decoder window and do exactly what it says. Then start again at 1.

A real computer runs this same cycle about a million times faster — and never gets bored.

Reading an instruction

Every word is three digits: 235 means op code 2 (ADD) applied to cell 35. Data words look exactly the same — what a word means depends only on where it is used. That one idea is the heart of every stored-program computer.

Current program

Pick a program above, or write your own: pencil words into the memory cells, put numbers on the input cards, place the bug on your first instruction and switch to Auto — or run the whole cycle yourself in Manual, the way it was meant to be.

Things worth knowing

  • Cell 00 permanently contains 001 — it is CARDIAC's entire boot ROM.
  • Op code 8 (JMP) writes its return address into cell 99 before jumping — a one-cell call stack.
  • Zero is a positive number. A countdown only escapes its loop because of this.
  • Reading a blank input card stops the machine — that's how the bootstrap loader knows it is finished.
  • Digits shifted out of the accumulator are gone for good; zeros take their place.
